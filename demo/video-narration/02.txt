Here is the request path. A buyer or seller agent calls a role-bound MCP tool. The Python MCP server passes the request into the Rust SDK. Rust owns the private keys, local state, proof request, account signature, submission, and recovery journal. The transaction prover reads Starknet state through an RPC and generates the proof used by the STRK20 pool. Each write has a durable operation I D, so a timeout is reconciled before anything can be retried.
