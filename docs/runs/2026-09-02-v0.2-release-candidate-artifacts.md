## Failure found

The first macOS MCP check stopped on this workflow assertion:

```text
AttributeError: 'CallToolResult' object has no attribute 'isError'. Did you mean: 'is_error'?
```

The published-package canary used the old `isError` field. MCP 2.1.1 uses `is_error`.

The release candidate packages were not defective. The unpublished canary workflow was defective. The workflow now uses `is_error`, and a regression test protects this field name.
