Against the L2 targets: `fund_wallet` 108.5 s (target 90 s, was 227 s); funded to first delivery 2.2 min (target 2 min, was 4.0); a second deal 2.5 min (target 90 s, was 4.2). Two targets are missed. This driver still calls the now-optional `check_settlement_funding` (33-43 s per deal); an agent following the new prompt skips it, which on these timings would put the first deal at about 100 s (an estimate, not measured). The second deal would still not meet 90 s: settle (about 43 s) plus payment verification (about 41-46 s, which includes Monad finality) leave no room, so reaching it needs the deferred persistent per-role worker that keeps verified state between calls.
